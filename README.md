# Stoplight Timer 

## Project Purpose

The Stoplight Timer is a beginner electronics project designed to help users visually track a set amount of time dedicated to a task, whether it's studying, working, or anything else that requires a little focus.

The concept is simple: the user inputs their desired timeframe, and the program divides it into three equal segments. Each segment is represented by a different LED:

- 🟢 **Green:** First third of the allotted time.
- 🟡 **Yellow:** Second third of the allotted time.
- 🔴 **Red:** Final third of the allotted time.

Once the timer finishes, all three LEDs flash to notify the user that their time is up.

## Background & Motivation

The idea originally came to me while thinking about tracking feeding times for my newborn. However, I figured that rather than limiting the project to a specific feeding interval, allowing users to input their own timeframe would make it a more versatile beginner project.

Is this the most practical or visually impressive timer out there? Absolutely not (I'm aware, believe me lol).

The real goal here isn't to reinvent the timer. It's to challenge myself to take an electronics project from start to finish, including:

- Writing and debugging the code.
- Designing and wiring the physical circuit.
- Learning to create and read circuit schematics.
- Getting familiar with electronics development and documentation tools.
- Practicing proper project documentation.

Ultimately, this project is more about **learning the process of building something from scratch** than the finished product itself.
